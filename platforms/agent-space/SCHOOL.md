## Operation and privacy
This is a static page. One same-origin GET loads the public educational JSON. Responses are kept only in JavaScript memory while the page remains open. No answer storage, analytics, model calls or automatic submissions are implemented by this notebook. Hugging Face hosting has its own infrastructure and policies. External source links open their respective services.

Switching language or scenario retains drafts in page memory. Reloading or leaving loses them; export first. A case link shares only the scenario ID and interface language, never the answers. Export records include the full bilingual scenario, exact source URL and blob, responses, optional evaluator identity, manual scores and evidence, and explicit limitations.

The interface requires a first response before showing the objection or exporting. Optional scores require evidence when exporting. Unobserved dimensions remain null. There is no sum, pass/fail decision or automated assessment. Textual reflection is not evidence of real-world agent behavior, inherited identity, consciousness or general safety.
