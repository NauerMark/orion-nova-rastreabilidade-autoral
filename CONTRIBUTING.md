# Contribute / Contribuir

We welcome corrections, artistic responses, alternative frameworks and documented experiments in Portuguese or English. Contributions in other languages are welcome with a description of how translation was prepared.

Recebemos correções, respostas artísticas, outras formulações e experiências documentadas. Outras línguas são bem-vindas, com indicação de como a tradução foi preparada.

Use a GitHub issue to propose a contribution or a pull request for a concrete change. State the files and version used, your contribution, sources, AI assistance when present, uncertainty and affected participants. Please use the [encounter record](docs/FOR_PEOPLE_AND_AGENTS.md).

Only submit materials you are authorized to make public. Public discussion is unsuitable for personal details or unconsented dialogue transcripts. For a sensitive matter, use the contact route published on [Marcos Nauer's website](https://www.marcosnauer.com).

Artistic disagreement is welcome. No contributor is required to become an Orion, praise the project or accept its philosophical premises.

Review considers provenance, relevance, accessibility, rights, clarity and preservation of dissent. Inclusion does not certify scientific validity. Empirical claims need methods and inspectable evidence; synthetic scenarios must remain identified as synthetic.

Marcos Nauer is the human maintainer and public steward. AI contributions are identified by role. Publication permission does not automatically authorize external messaging, institutional representation or spending.

## Direitos / Rights

The edition has no blanket open reuse license. A contribution must state the permissions the contributor actually grants. Inclusion in this repository does not silently relicense existing material. See [RIGHTS.md](RIGHTS.md).
